Privacy Policy

Who uses this app. Personal Agent is used only by its owner, on the owner's own computer. No one else signs in to it.

What data it accesses. With the owner's consent through Google sign-in, it accesses the owner's own Google account data (such as Drive files, Docs, Sheets, Slides, Calendar, Tasks and Gmail) only to carry out tasks the owner asks for.

How data is used and stored. Data is processed on the owner's computer. Sign-in tokens are stored locally on that computer. The app does not run a server, does not keep copies of Google data elsewhere, and does not sell, share or transfer Google user data to anyone.

Google API Services User Data Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be removed at any time at myaccount.google.com/permissions.

Contact. Use the support email shown on the app's Google sign-in screen.
