Personal Agent

Personal Agent is a private tool used only by its owner. It runs on the owner's own computer and uses Google sign-in so that the owner's local scripts can read and update the owner's own Google Drive files, Docs, Sheets and Slides (for example, building study materials and presentation decks).

It is not offered to the public, has no other users and is not a commercial service.
